Title: Shohag Loves Strings

Description:
Shohag has discovered that for any string p, there's a special property: the number of distinct non-empty substrings it contains. Your challenge is to find a non-empty substring p within the given string s such that the count of distinct non-empty substrings in p is even. If no such substring exists, output -1. If several substrings qualify, output the shortest one; if several shortest ones exist, output the leftmost one (the one that starts earliest in s).

Input Format:
The first line contains t (1 ≤ t ≤ 10^4), the number of test cases. Each of the next t lines contains a single string s (1 ≤ |s| ≤ 10^5) consisting of lowercase English letters.

Output Format:
For each test case, output one line: the shortest non-empty substring p of s that has an even number of distinct non-empty substrings (the leftmost one if several of the same length exist), or -1 if no such substring exists.

Score: 75

isjunior: True

Time Limit: 1

Memory Limit: 256
