Problem: Minimum Number of Days to Make m Bouquets

Statement:
You are given an integer array bloomDay, an integer m, and an integer k.
You want to make m bouquets. To make a bouquet, you need to use k adjacent flowers from the garden.
The garden consists of n flowers, where the ith flower will bloom on bloomDay[i] and can then be used in exactly one bouquet.
Return the minimum number of days you need to wait to be able to make m bouquets from the garden. If it is impossible to make m bouquets, return -1.

Input Format:
The first line contains three space-separated integers: n, m, and k, representing:
  - n: the number of flowers in the garden
  - m: the number of bouquets needed
  - k: the number of adjacent flowers required per bouquet
The second line contains n space-separated integers: bloomDay[0], bloomDay[1], ..., bloomDay[n-1], where bloomDay[i] indicates the day on which flower i blooms.

Output Format:
Print a single integer: the minimum number of days you need to wait to make m bouquets, or -1 if it is impossible.

Example 1:
Input:
5 3 1
1 10 3 10 2
Output:
3
Explanation:
We need 3 bouquets each containing 1 flower.
After day 1: [x, _, _, _, _] (1 bouquet)
After day 2: [x, _, _, _, x] (2 bouquets)
After day 3: [x, _, x, _, x] (3 bouquets)
The minimum days required is 3.

Example 2:
Input:
5 3 2
1 10 3 10 2
Output:
-1
Explanation:
We need 3 bouquets each containing 2 flowers, requiring a total of 6 flowers. Since there are only 5 flowers in the garden, it is impossible, so return -1.

Example 3:
Input:
7 2 3
7 7 7 7 12 7 7
Output:
12
Explanation:
We need 2 bouquets of 3 flowers each.
After day 7: [x, x, x, x, _, x, x]
We can make one bouquet from the first three flowers [0..2]. The remaining flowers [3] and [5..6] cannot form another bouquet because they are separated by an unbloomed flower at index 4.
After day 12: all flowers have bloomed, allowing two bouquets to be formed.
